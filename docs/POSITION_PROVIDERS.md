# Источники позиций

`PositionProvider.observe(item_id, SearchQuery) -> PositionSnapshot` — асинхронный
контракт внешнего разрешённого источника. Реального URL нет: поставщик не выбран.
Адаптер обязан проверять принадлежность результата ID/запросу/региону, передавать
время самого наблюдения с часовым поясом, тип выдачи, статус и обоснованную confidence.
Средняя позиция обозначается AVERAGE и не поступает в алгоритм точных мест.

`UnavailablePositionProvider` возвращает UNAVAILABLE без позиции.
`MockPositionProvider` выдаёт явную тестовую последовательность. Playwright
не установлен; обход CAPTCHA или антибот-защиты не предусмотрен.

Ручной импорт: `app.positions.manual.import_observations(Path(...))` читает JSON-массив:

```json
[{"item_id": 123, "search_query": "запрос", "region": "Москва",
  "position": 6, "position_type": "MIXED",
  "checked_at": "2026-11-16T12:00:00Z", "provider": "manual",
  "confidence": "0.9", "status": "FOUND"}]
```

Это пример формата, не реальное наблюдение. Импорт валидирует схему и дубликаты,
но не подтверждает истинность введённых данных. Для NOT_FOUND_IN_CHECKED_RANGE,
UNAVAILABLE, INVALID_DATA, RATE_LIMITED `position` должна быть null. Время хранится
в UTC при записи; исторические данные доступны только для воспроизведения и не
должны повышать текущую ставку. Подключение импорта к периодическому мониторингу
и пользовательскому интерфейсу остаётся отдельной задачей.

Backtest: `app.bidding.backtest.backtest(engine, item, info, frames)` возвращает
рекомендации с `simulated=true`. Он не моделирует причинное влияние ставки на
позиции и не доказывает экономию на реальном аукционе.
