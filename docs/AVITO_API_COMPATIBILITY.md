# Совместимость Avito API

## Фаза 7. Проверка 16 ноября 2026

Официальные страницы OAuth, CPX, аукциона и статистики из доступной среды не открылись. Актуальных официальных экспортов и credentials для проверки аккаунта в этой фазе не было. Совпадение с закреплённым снимком используется для mock-регрессии. Для сетевых запросов требуется совпадение контракта с OpenAPI-экспортом, полученным владельцем. [Официальный каталог Авито](https://developers.avito.ru/api-catalog).

| Семейство | Реализованное чтение при совпадении схемы | Запись, сверка и ограничения |
|---|---|---|
| OAuth и аккаунт | Client Credentials, обновление кэша, account self, страница объявлений и запрос объявления в контексте аккаунта | Реальные scopes и условия выдачи токена не подтверждены |
| CPX manual | `getBids`, `getPromotionsByItemIds`, тип действия, текущая ручная ставка и границы из ответа | `saveManualBid` и сверка ставки с параметрами проверены на mock. Право записи, доступность модели и единицы параметров требуют официальной проверки |
| CPX auto | Чтение типа настройки и признаков продвижения | Управление автоматическими параметрами не реализовано |
| CPA-аукцион | `getUserBids`, курсор, текущая ставка и дискретные `availablePrices` | `saveItemBids` и сверка ставки со сроком проверены на mock. Права, категории, лимиты и правила срока требуют официальной проверки |
| Услуги, CPC как отдельная модель, кабинет Ads | Частичное чтение услуг через `get_services_by_items_v2` | Платный адаптер отсутствует |
| Статистика | `itemStatsShallow`, `itemAnalytics`, `accountSpendings`. Числа читаются через Decimal | Полнота периода, актуальность и лаг не подтверждены. Сетевой сбор не формирует надёжный вход бюджета |
| Оперативная выдача | Работают сценарии mock и ручной импорт. Разрешённый реальный адаптер не подключён | Оперативность, сопоставимость и покрытие для AUTO не подтверждены |

Повторы применяются к чтению и ограничены. Для 429 учитывается Retry-After, а для отдельных операций действуют интервалы из реализации по снимку. Актуальные квоты и коллективное потребление аккаунта остаются предметом реальной проверки. Сетевой транспорт разрешает только именованные операции чтения и обмен credentials на токен. Возможность записи обозначена `UNVERIFIED`.

| itemAnalytics, accountSpendings | Эффективность, расходы | Decimal, до одного запроса в минуту по снимку |

CPC не трактуется как отдельный подтверждённый механизм управления объявлениями.
CPX описывает целевое действие с actionTypeID; CPA-аукцион использует дискретные
availablePrices. Услуги продвижения и рекламный кабинет Ads не подменяют эти модели.
Тарифы, категории, доступность конкретных действий и задержки финансовых данных
не подтверждены для аккаунта. Успешное чтение не доказывает право записи.
Расходы пока не преобразуются в `Spending(reliable=True)` для бюджетного движка.

Дата проверки: 16 ноября 2026, Europe/Moscow.

**Статус: BLOCKED для реальных операций.** Ни один контракт записи не подтверждён
по актуальной официальной документации и на аккаунте владельца. Наличие имени
метода в задании или справочнике не означает доступность функции.

## Что требуется перед интеграцией

1. Получить актуальные OpenAPI/документацию из кабинета разработчика Авито, включая
   auth, account/item, выбранную модель продвижения и статистику.
2. Установить модель продвижения, категорию и тариф для каждого из 1–5 ID.
3. Подключить credentials через окружение; не присылать секреты в чат и не коммитить.
4. Выполнить отдельную проверку чтения аккаунта, принадлежности объявлений,
   прав, доступных ставок, срока и свежести финансовой статистики.
5. Выбрать разрешённый источник позиций. Среднюю позицию нельзя подменять точной.
6. Реализовать и проверить реальный адаптер, повторную проверку бюджетов, подтверждения
   и сверку после неопределённой записи; только затем запросить явное разрешение
   владельца на конкретную платную операцию на одном объявлении.

Нельзя обещать точную остановку списаний по запаздывающей статистике. Локальный
бюджетный guard не останавливает ранее подключённое продвижение на стороне Авито.
Система не заменяет неподдерживаемую ставку покупкой услуги.
